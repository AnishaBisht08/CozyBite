# 🍳 CozyByte

CozyByte is a recipe app built with **Kotlin and Jetpack Compose**.
Users can explore recipes, search for meals, view recipe details, save favorites, and create their own recipes.

## ✨ Features

* 🔐 Firebase Authentication
* 🏠 Browse recipes
* 🔎 Search recipes
* 📂 Recipe categories
* 📖 Recipe details
* ❤️ Save favorite recipes
* ➕ Create your own recipes
* 👩‍🍳 View user-created recipes
* 🌐 Fetch recipes from an API
* 💾 Store favorites locally

## 🛠️ Tech Stack

* **Kotlin**
* **Jetpack Compose**
* **MVVM**
* **StateFlow**
* **Coroutines**
* **Retrofit**
* **Gson**
* **Coil**
* **Room Database**
* **Firebase Authentication**
* **Navigation Compose**

## 🧠 What I Learned

While building CozyByte, I practiced:

* Building UI with Jetpack Compose
* Managing UI state with StateFlow
* Working with REST APIs using Retrofit
* Loading network images with Coil
* Saving data locally with Room
* Firebase Authentication
* Navigation between Compose screens
* Creating reusable composables
* Structuring an Android app using MVVM
